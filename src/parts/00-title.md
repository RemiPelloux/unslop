# UNSLOP

A design and writing rulebook for interfaces that do not look or read like they came out of a model on default settings.

Feed this file to a coding agent as context, or read it yourself before a review. Every rule in it is enforceable: each one names the default it replaces, the values to use instead, and a way to check for it.

The file practices what it preaches. It contains no box shadows outside of quarantined bad examples, no emoji, no glowing status pills, no blue or purple gradients, no em dashes, no exclamation marks, and none of the 350 banned words in its own prose. Banned words appear only as mentions: inside inline code, or inside code fences tagged `slop`, which hold the bad examples. `scripts/lint.py` in the source repository checks all of this on every build.
