#### 274. `moreover`

- Kind: adverb, connective. Banned forms: `moreover`.
- Why it reads as machine text: `moreover` claims the next point strengthens the last one, and models use it even when the next point is unrelated. It is rare in speech and common in generated essays, where it can open every third paragraph. It pushes the reader to read a list as a building case.
- Where it shows up: essay answers, persuasive copy, academic-style summaries.

```slop
Moreover, the library has excellent documentation.
The plan is cheaper. Moreover, it includes support.
Moreover, this approach scales well.
```

Replace with:

- Start the sentence with the claim; its position already marks it as the next point.
- "also" for a point of similar weight: "The plan also includes support."
- "and" to join two short claims in one sentence.
- Cut it when the connective is propping up a weak point; drop the point too.

Rewrites:

```slop
Moreover, the library has excellent documentation.
```

After: The library documents every function with an example that runs.

```slop
The plan is cheaper. Moreover, it includes support.
```

After: The plan is cheaper and includes email support.

```slop
Moreover, this approach scales well.
```

After: The same setup handled 50,000 requests a minute on 4 servers in our load test.

- Literal use: the word has no literal sense; start with the claim, or use "also" or "and".
