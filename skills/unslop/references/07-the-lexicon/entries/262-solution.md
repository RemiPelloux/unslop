#### 262. `solution`

- Kind: noun. Banned forms: `solution`, `solutions`.
- Why it reads as machine text: `solution` is the default noun in B2B copy for any product, and models carry it everywhere: `our solution`, `end-to-end solutions`, `the solution for teams`. It avoids saying what the product is: a database, an app, a service. In technical answers, `Here's a solution` adds nothing before the code.
- Where it shows up: B2B landing pages, sales emails, model answers to coding questions.

```slop
Our all-in-one solution helps teams collaborate better.
We provide enterprise solutions for supply chain management.
Here's a solution that should fix your issue.
```

Replace with:

- The product type: "app", "API", "database", "service", "plugin".
- "fix", "answer" or "workaround" in support and code answers.
- "way" when you mean a method: "one way to do this is".
- Cut it when the code or steps follow directly; start with them.

Rewrites:

```slop
Our all-in-one solution helps teams collaborate better.
```

After: A shared inbox app for support teams, with assignments and internal notes.

```slop
We provide enterprise solutions for supply chain management.
```

After: We sell inventory and shipping software to warehouses with 50 to 500 staff.

```slop
Here's a solution that should fix your issue.
```

After: Set `"moduleResolution": "bundler"` in `tsconfig.json`, and the import error goes away.

- Literal use: in chemistry, give the mix ("0.9% saline") or put `solution` in inline code; for a Visual Studio project file, write `.sln` in inline code; in math, write "answer" or give the value.
